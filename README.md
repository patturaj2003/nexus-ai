# 🚀 Nexus AI Assistant  

🔗 **Live Demo:** https://nexus-ai-assistant-nine.vercel.app/  

Nexus AI Assistant is a modern, voice-enabled intelligent assistant built to enhance productivity through real-time communication, smart automation, and seamless user interaction.  

---

## ✨ Key Features  

- 💬 **AI-Powered Chatbot**  
  Conversational assistant powered by Puter.js with text-to-speech  

- 🎤 **Voice-Enabled Interaction**  
  Real-time voice input and output using Web Speech API  

- 📱 **Telegram Integration**  
  Real-time messaging via Telegram Bot API  

- ⏰ **Smart Reminder System**  
  Voice-enabled reminders and alerts  

- 📊 **Activity Tracking**  
  Tracks user interaction history  

- 🔐 **Secure Authentication**  
  Managed using Supabase  

---

## 🛠️ Tech Stack  

- Frontend: React.js, CSS3, Web Speech API  
- Backend: Node.js, Express.js  
- Database: Supabase (PostgreSQL)  
- Authentication: Supabase Auth  
- AI: Puter.js
